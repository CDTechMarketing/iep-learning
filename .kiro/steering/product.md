# Product Overview

IEP Learning is an educational web application designed for special needs students, particularly those with IEPs (Individualized Education Programs). The app provides structured learning activities in reading, math, and science with built-in accessibility features and progress tracking.

## Core Features

- **Reading Practice**: CVC word families and progressive phrase building
- **Math Practice**: Number identification, addition with manipulatives, counting activities (number lines, ten frames, touch counting)
- **Science Activities**: Simple machines, forces, and mechanical concepts
- **Visual Schedules**: Session planning with activity previews
- **Sensory Breaks**: Built-in break activities (breathing exercises, bubble pop, color swirls)
- **Reward System**: Star-based progression with milestone rewards
- **Choice Boards**: Student-directed activity selection
- **Parent Dashboard**: Progress tracking and session analytics

## Target Users

- **Primary**: Students with special needs (ages 5-12)
- **Secondary**: Parents, teachers, and caregivers monitoring progress

## Key Design Principles

- **Accessibility First**: Dyslexia-friendly fonts, high contrast modes, reduced animations
- **Privacy**: All data stored locally in IndexedDB (no external services)
- **Adaptive Support**: Configurable prompting levels (full, partial, minimal, independent, adaptive)
- **Positive Reinforcement**: Immediate rewards, visual feedback, celebration animations
