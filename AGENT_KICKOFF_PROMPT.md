# Agent Development Kickoff Prompt Template

Use this prompt to start development on any Wave 1 agent. Replace `[AGENT_NUMBER]` and `[AGENT_NAME]` with the specific agent you want to build.

---

## Prompt Template

```
I want to implement Agent [AGENT_NUMBER]: [AGENT_NAME] for the IEP Learning Platform.

📋 **Specification Documents**:
The complete specifications are located in the repository branch:
`claude/agent-6-math-operations-01Pa5Soh8gbRUNei85A2jmcf`

Please review these two documents:

1. **WAVE_1_AGENT_PROMPTS.md** - Contains the detailed specification for Agent [AGENT_NUMBER] including:
   - Purpose and key features
   - Data schema (TypeScript interfaces)
   - Implementation phases with time estimates
   - UI components needed
   - Logic and algorithms required

2. **WAVE_1_IMPLEMENTATION_TRACKING.md** - Contains:
   - Current implementation status
   - What's already been completed
   - Integration checklist
   - Success metrics
   - Recommended next steps

🎯 **Your Task**:
1. Read both specification documents from the branch mentioned above
2. Review the detailed requirements for Agent [AGENT_NUMBER] in WAVE_1_AGENT_PROMPTS.md
3. Create a new development branch: `claude/agent-[AGENT_NUMBER]-[agent-name]-[session-id]`
4. Implement the agent following the phases outlined in the specification
5. Use the integration checklist from WAVE_1_IMPLEMENTATION_TRACKING.md
6. Update the tracking document with your progress
7. Commit and push all changes to your new branch

📊 **Standards Alignment**:
Ensure your implementation aligns with the Virginia SOL standards specified in the agent documentation.

🎨 **Design Principles**:
- Follow Universal Design for Learning (UDL) guidelines
- Maintain accessibility (WCAG 2.1 AA)
- Use consistent patterns from existing agents (Agents 5, 6, 7)
- Implement multi-sensory learning approaches
- Include scaffolding and adaptive difficulty

Let me know when you've reviewed the specifications and are ready to begin implementation!
```

## Tips for Success

1. **Always review existing agents first** (5, 6, 7) to understand patterns
2. **Follow the integration checklist** to ensure nothing is missed
3. **Update tracking document** as you complete phases
4. **Commit frequently** with descriptive messages
5. **Test accessibility features** throughout development
6. **Document as you go** - don't leave it for the end
