## Standup Guidelines

### When to Update
- **Preferred:** End of each work day
- **Alternative:** Start of next work day
- **Frequency:** Daily during active development

### What to Include

#### Accomplishments
- Focus on completed work
- Be specific (not just "worked on feature X")
- Include metrics when possible
- Highlight milestones

#### Metrics
- Feature completion percentage
- Agent velocity
- Blocker count
- Merge status
- Any other relevant numbers

#### Tomorrow's Priorities
- Max 3-5 items
- Be realistic
- Consider dependencies
- Note if priorities shifted

#### Blockers
- Any impediment to progress
- Who/what is blocked
- Action plan to resolve
- Expected resolution time

#### Celebrations
- Feature completions
- Successful merges
- Milestones reached
- Zero blockers
- Any wins worth noting

### Keep It Brief
- This is a snapshot, not a novel
- Details go in specific PM documents
- Link to other documents for context
- Focus on high-level status
